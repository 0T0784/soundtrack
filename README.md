## ◆１．はじめに

この度は私のhtmlをダウンロード及びご鑑賞いただき、まことにありがとうございます。

このhtmlでは、幻視をすることができるコンポーザーが自らの魂を振り絞って生み出した作品群です。音楽ラブな方々やマニアな方々、はたまたマイナーな方々も楽しんで（？）いただけたら幸いです。詳しい操作方法については`manual.jpg`をご覧ください。それでは、みなさんのお時間が尽きる前にお楽しみください。

## ◆２．使用方法

お使いのPCのSafariやGoogle ChromeなどのChromium搭載ブラウザなどでお楽しみいただけます。スマホ対応は人気があれば後々。

Googleドライブなどからは直接起動できません。一度ダウンロードしていただき、起動していただきますようお願いします。

## ◆３．予めご理解いただきたいこと

本作品は、高校の卒業制作展に向けて制作した作品です。まだまだ、学生の身でクオリティなどが十分に保証ができません。また、ＰＣのブラウザでは動作確認済みですが、スマホでのご閲覧は現状サポート対象外ですので、悪しからず。あと、無断転載はおやめくださいね。

## ◆４．困ったことがあったら

htmlが動作しない場合`audio`フォルダに楽曲のデータを同梱してあります。どうしても別アプリで再生したい場合などにもご利用いただけると思います。
